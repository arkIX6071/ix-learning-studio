ทำนายก่อน: ตั้ง GCP = 3 จุด แล้ว RMSE ที่ GCP จะมีค่าเท่าไร? ภาพจะแม่นยำ 100% หรือไม่?

RMSE ที่ GCP = 0 เสมอ เพราะสมการ 6 สมการมีตัวไม่ทราบค่า 6 ตัวพอดี (r = 0) ระนาบจึงลากผ่านทุกจุดได้โดยอัตโนมัติ ค่า 0 นี้มาจากเลขคณิต ไม่ได้มาจากความแม่นยำ ให้ดู RMSE ที่ check point ซึ่งไม่ได้ใช้ในการ fit เป็นหลักฐานอิสระ ส่วน noise ของการชี้ GCP จะเข้าไปปนในค่าสัมประสิทธิ์โดยไม่มีใครเห็น เปรียบกับงานรังวัด: วงรอบที่ไม่มีค่าสังเกตเกินจะ “ปิดสนิท” เสมอ แต่ไม่ได้แปลว่าวัดถูก

ทำนายก่อน: เปลี่ยนเป็น “GCP กระจุกมุมเดียว” แล้ว RMSE ที่ GCP กับ RMSE ที่ check point จะเปลี่ยนอย่างไร?

RMSE ที่ GCP อาจยังเล็ก แต่ RMSE ที่ check point ซึ่งอยู่ไกลจาก GCP จะโตขึ้น เพราะแบบจำลองกำลัง extrapolate ออกไปนอกบริเวณที่มีข้อมูล ความคลาดเคลื่อนเล็กน้อยของการชี้ GCP จึงถูกขยายตามระยะทาง แนวคิดนี้แสดงด้วยแบบจำลองและข้อมูลสังเคราะห์ ผลนี้จะยิ่งรุนแรงกับ polynomial ลำดับสูง

03 / Radiometric Correction — ทำให้ค่ามีความหมายทางฟิสิกส์

Detector ถูกออกแบบให้ตอบสนองแบบเชิงเส้นต่อ spectral radiance ถ้ารู้ gain และ offset ของ sensor ก็ย้อนจาก DN กลับเป็น radiance ได้ แนวคิดทั่วไป

DN = G·L + B  ⇔  L = (DN − B)/G  =  Lmin + DN·(Lmax − Lmin)/DNmax

หน่วยแบบจำลอง: ทุกค่า radiance ในบททดลอง (L, Lmin, Lmax, Lp, Ltot) ใช้ W m⁻² sr⁻¹ µm⁻¹; G ใช้ DN ต่อหน่วย radiance; B เป็น DN; reflectance ρ และ transmittance T ไม่มีหน่วย ค่าตัวเลขเป็นค่าจำลอง ไม่ใช่ calibration metadata จาก sensor จริง

  • G = DNmax/(Lmax − Lmin), B = −G·Lmin สามรูปนี้คือสมการเดียวกัน แนวคิดทั่วไป
  • Lmin = radiance ที่ให้ DN = 0, Lmax = radiance ต่ำสุดที่ทำให้ DN = DNmax (จุดอิ่มตัว) แนวคิดทั่วไป
  • บางเอกสารใช้หน่วย mW cm⁻² sr⁻¹ µm⁻¹ (Landsat ยุคเก่า) · 1 mW cm⁻² sr⁻¹ µm⁻¹ = 10 W m⁻² sr⁻¹ µm⁻¹ ซึ่งเป็นหน่วยที่ metadata ปัจจุบันใช้ คำอธิบายเสริม
  • ค่า Lmin, Lmax, G, B เป็นค่าเฉพาะของแต่ละ sensor และแต่ละแบนด์ ต้องอ่านจาก metadata ของภาพนั้น
