01 / หลักการ

คำถาม: เราใช้พิกัดที่ epoch 2021.93 ไปกับงาน epoch 2026.79 โดยไม่คำนวณเพิ่มเติมได้เสมอหรือไม่?

ไม่ได้เสมอไป จุดรังวัดอาจเคลื่อนตัวตามเวลา ในแบบจำลองง่ายที่ความเร็วคงที่ เราคำนวณการเปลี่ยนพิกัดจาก ความเร็ว × ระยะเวลา แล้วนำไปบวกกับพิกัดเดิม

ข้อเท็จจริง → กลไก → คำนวณ → ตรวจข้อจำกัด เป็นลำดับการเรียนรู้ของบทนี้

p(t) = p(t₀) + v × (t − t₀)
พิกัดเริ่มต้น [m] + ความเร็ว [m/year] × เวลา [year]
σE(t) = √(σE₀² + Δt²σvE²)
1σ เฉพาะแกน East; สมมติ covariance = 0 และ epoch รู้แน่นอน

03 / สิ่งที่เราเรียนรู้

ค่า Epoch เปลี่ยน: Δt เปลี่ยน จึงเปลี่ยน displacement และ uncertainty จาก velocity
Velocity เป็นศูนย์: พิกัดไม่เปลี่ยนในแบบจำลองนี้ แม้เวลาจะผ่านไป
Epoch ก่อน t₀: Δt ติดลบ ทิศทางของ displacement จึงกลับกัน
ข้อจำกัด: สูตรนี้เป็น Local ENU คงที่ ยังไม่ใช่ ITRF frame transformation และยังไม่รวม post-seismic, seasonal หรือ discontinuities
